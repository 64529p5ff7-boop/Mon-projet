# Skills motion design

Copie de sauvegarde des skills utilisés pour les vidéos animées (style « Une minute avec… »).
Placés dans `.claude/skills/`, ils sont chargés automatiquement par Claude Code dans ce dépôt.

| Skill | À quoi il sert |
|---|---|
| `analyse-reference-motion` | Décortiquer une vidéo d'inspiration : plans, rythme, palette, typo, fiche de style |
| `motion-design-code` | Pipeline complet en code : brief, beat map, moteur HTML `seek(t)`, rendu Playwright + ffmpeg, son, QA |
| `motion-promo-animatic` | Transformer un storyboard en animation (16:9 et 9:16) |
| `saas-motion-video` | Promo d'app ou de SaaS en 7 étapes avec validations |
| `tiktok-habillage-vertical` | Habiller une vidéo 16:9 en 9:16 pour TikTok (titre, pastille d'appel à commenter) |
